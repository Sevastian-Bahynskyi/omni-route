HOW TO USE OMNI ROUTENEW SESSIONS // ROTATION // HANDOFFS // PARALLEL WORK

Choose the harness once when you start a task. Omni Route selects the account, watches its limits, and keeps the session moving through the pool.

01 // START A SESSION

In OmniAgent, choose Codex or Claude Code in the new-session composer, select the project folder, then send the first prompt. That harness choice controls the new session; the dashboard's Current Account applies only to the Controlled Session.

02 // LET ACCOUNTS ROTATE

Keep working normally. At the configured threshold, Omni Route cools the account and tries another account from the same provider first. If that whole provider is unavailable, it switches harnesses and continues through the other provider automatically.

03 // SWITCH MANUALLY

Choose a session under Controlled Session, then choose any account under Current Account. A same-provider change relaunches that harness with the selected login. A cross-provider change hands the existing conversation and workspace to the new harness.

04 // RUN PARALLEL WORK

Create several OmniAgent sessions and choose Codex or Claude independently in each composer. Every session keeps its own account binding, provider, history, workspace, cooldown state, and rotation path.

05 // SET PRIORITY

Drag accounts in Route Chain. Rotation prefers available accounts of the current provider in that order, then the first available account from another provider. Next Account previews the choice for the controlled session.

06 // READ LIMITS

short is the provider's shorter usage window and weekly is the longer window. A cooling account is skipped until its reset. If every account is unavailable, the session waits in an exhausted state until one recovers.

EXAMPLE // ONE LONG TASK
  • In OmniAgent select Codex, choose the CoupleGoAI folder, and send: Implement issue #424 and run the focused tests.
  • With route codex-2 → codex-1 → claude-1 → claude-3, the session starts on codex-2, rotates to codex-1, then hands off to claude-1 only after both Codex accounts are unavailable.
  • Keep replying in the same OmniAgent session. You do not need to copy prompts or create a replacement session after rotation.
EXAMPLE // TWO TASKS AT ONCE
  • Session A: select Codex and ask it to fix authentication.
  • Session B: select Claude Code and ask it to review onboarding copy.
  • Use Controlled Session on this dashboard before manually changing an account. The other session remains unchanged.
